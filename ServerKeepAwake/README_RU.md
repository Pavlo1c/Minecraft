# ServerKeepAwake — NeoForge 1.21.1

Серверный мод для Windows. Пока выделенный Minecraft-сервер работает, мод регулярно вызывает Windows API `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED)`, чтобы Windows не переводила ПК в сон.

При штатной остановке сервера мод снимает запрос (`ES_CONTINUOUS`). Если процесс Java аварийно завершается целиком, Windows очищает состояние вместе с завершившимся процессом. Мод не меняет выбранный план электропитания и не имитирует ввод с клавиатуры/мыши.

## Совместимость

- Minecraft 1.21.1
- NeoForge 21.1.265
- Java 21
- Windows 10/11 (на других ОС мод ничего не делает)

## Установка

После сборки скопировать JAR из GitHub Release в серверную папку `mods`. Клиентам игроков ничего устанавливать не нужно: мод не добавляет сетевых каналов и предназначен только для сервера.

## Сборка

Сборка выполняется автоматически на GitHub Actions при изменениях в этой папке. Для публикации версии создаётся тег вида `serverkeepawake-v1.0.0`. Готовый JAR прикрепляется к GitHub Release.

## Важные детали

- Используется только `ES_SYSTEM_REQUIRED`: монитор может выключаться по обычному таймеру, но сам ПК не должен уходить в сон.
- Запрос обновляется каждые 30 секунд отдельным daemon-потоком.
- При проблеме с JNA/Windows API мод пишет ошибку в лог, но сервер продолжает работать.
- JNA включена в JAR через Jar-in-Jar; отдельная библиотека на сервере не нужна.
