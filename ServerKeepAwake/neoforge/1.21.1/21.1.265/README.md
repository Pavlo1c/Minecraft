# ServerKeepAwake — NeoForge / Minecraft 1.21.1 / NeoForge 21.1.265

Эта сборка предназначена для выделенного сервера Minecraft 1.21.1 на NeoForge 21.1.265 и Java 21.

Исходники и Gradle-конфигурация находятся в этой папке. JAR публикуется с именем `ServerKeepAwake-neoforge-MC1.21.1-NF21.1.265-v1.0.0.jar`.

Клиентам игроков мод устанавливать не нужно. Поддерживается Windows 10/11; на других ОС мод не активирует Windows API.
